# 极小模型场景与界面对照

本轮按用户请求增加真实的小模型实验，并扩大 demo 对照范围。它属于独立实验示例，不改变平台仅管理模块契约和 Pod 启动的边界。模块内部自行实现检索、模型调用、识别及合成。

## 实际场景结果

虚拟 Acorn Mini Store 项目、三条政策和五个模块在 `testflow-e2e-20261011-09` 实际运行。十项场景检查通过：真实会话、Git 固定 commit、五个真实 Pod 的契约和 imageID、音频及图片导入、三条完整模型链路、真实 Kimi 结构化复评、重跑与固定旧报告、模块资源回收。

| 输入 | 实际识别/检索 | 实际生成与产物 |
| --- | --- | --- |
| 文字 | BM25 检索返回退货政策文档 | Kimi `k3` 正常完成、23 个输出片段；英文回答引用 `[returns]`，生成 16kHz mono PCM16 WAV |
| 合成音频 | PocketSphinx 输出 `what is the refund policy` | Kimi 正常完成、7 个输出片段；同一退货政策回答和可播放 WAV |
| 图片 | Tesseract 输出 `What is the refund policy?` | Kimi 正常完成、23 个输出片段；同一回答和可播放 WAV |

三条回答均包含 14 天退货期限及引用，输出音频各 125,282 个采样点。三条规则评测通过；Kimi 根据实际回答与检索证据进行的 `json_schema` 复评也通过。重跑创建新实例，原报告不变，计划分母保持三条。

ASR 模型约 6.30 MiB，OCR 数据约 3.92 MiB，TTS 语言数据约 11.09 MiB；BM25 无权重下载，Kimi 为远程 API。体积指模型/数据，不指完整容器。ASR 为英文限定语法，图片测试为英文 OCR，TTS 使用共振峰合成；不宣称中文、自由语音、通用视觉或生成质量通过。没有使用麦克风。

完整源码和复现步骤见 [实验说明](../../examples/scenarios/tiny-helpdesk/README.md)。实际证据和音频保存在 `.data/acceptance/testflow-e2e-20261011-09/`，密钥不进入这些产物。

## 界面修正与对照口径

统一关闭按钮的尺寸、底色和图标，统一表单标签和多行输入框。执行详情恢复材料预览卡片、独立参考、完整输出状态、六列摘要和紧凑页签；默认选中第一个模块，区分评测错误与执行错误。流程画布补充模块/内置节点分组、未选节点时的流程配置、完整组连线列表及删除确认。结束节点不重复显示 OUT；相应测试使用真实 SVG 线段中点点击，避免把零高度的水平几何框当作不可见。

新建流程补齐开始节点名称、初始输入和统一输出选项；仍支持创建后任意编辑有序字段组。选择不同输入输出时不生成隐式连线或转换，取消后草稿保留。

九个主页面继续使用统一夹具、1440×1000、无遮罩的 0.5% 严格像素门槛。新增加的十三个状态另行保存同条件截图和差异：文字/流程/测试集/仓库弹窗，测试集详情、流程画布、六个执行页签和任务报告。

**界面不能称为完美还原。** 十三状态的诊断有明显差异，包括新建测试集/仓库表单、画布工具栏与节点布局、详情的证据和任务报告。一部分来自实际凭据、接口和版本控件，一部分仍是布局差异。该诊断没有扩大遮罩，也没有通过复制原型 HTML 来替代正式组件。新增控件按同一 Tokens/HeroUI 规范实现，但不能把功能通过当作所有状态的像素通过。

最终 `09-final` 的标准 Playwright 14 项全部通过：84 个控件、163 条用例及 408 个状态组合。最后的表单间距调整另外通过真实场景浏览器的 13 项检查和新建流程的 12 个宽度/语言/主题组合；实际浏览器播放生成的 WAV、查看三条成功报告、六个执行页签及真实 Kimi 评分。类型检查、生产构建、19 项原型/清单测试及四项 Trace 脱敏器测试通过；两个实际 Trace 的独立审计未发现密钥、密码或会话泄漏。

九页严格视觉最大差异仍为 0.484%，无遮罩。十三个扩展状态的差异为 0.805%–10.503%，未达到 0.5% 门槛；新建流程弹窗从约 11.286% 降至 3.573%。这些诊断不计为通过。失败和中断的调试记录保留。

测试 namespace、其 Pod/PVC/PV 和 port-forward 已回收；正常 `testflow-dev` 前后端及 PostgreSQL Ready，迁移完成。正常部署已更新，默认工作区没有导入实验数据。

最终证据：`.data/acceptance/scenario-20261011/result.json`；真实场景 `.data/acceptance/testflow-e2e-20261011-09/tiny-scenario.json`；浏览器附加检查同目录 `scenario-ui/result.json`；完整标准浏览器 `.data/browser-results/09-final/`；扩展像素诊断 `scenario-20261011/detail-delivery/result.json`；资源回收同 namespace 的 `cleanup.json` 和 `scenario-20261011/cluster.json`。可播放的独立报告保存在 `scenario-20261011/report.html`。
