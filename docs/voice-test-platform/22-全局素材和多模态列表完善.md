## 引用与历史

案例输入为全局素材 ID 或独立字面量；当前案例按 ID 解析最新内容。创建任务时冻结实际资源版本、输入、参考及参考来源，同一计划中的相同素材只解析一次，排队项不会因后续修改改变。原有任务的重跑和旧报告继续使用已冻结记录。

案例参考可独立保存，也可通过 `reference_assets` 显式关联素材参考标准。绑定后其内容和确认状态来自素材池，在任务计划中冻结；参考不会进入执行输入。导入导出保留这种绑定，用文件内依赖键代替环境 ID。正式界面导出当前素材修订，API 也保留指定测试集结构/成员版本的导出。

资源新增、修订、删除和恢复在同一数据库事务中追加可回补的 `resource.changed` 事件，只广播资源身份及版本，不含正文；其他已打开页面的素材选项和预览随实时连接刷新。

素材文件按内容摘要保存。文字修改产生新 UTF-8 文件；音频、图片的原文件不覆盖。固定版本的媒体 URI 可长期缓存，当前素材 URI 使用 no-cache。音频源修订变化时重新绑定播放器 URI，避免 React 更新后的清理移除新地址。
