# 输入组、素材只读预览与简化工作区

2026-10-12，按最新九项反馈调整产品边界。此记录取代第 22 篇中的“测试集输出/参考”和“各列表直接编辑素材”。

## 交付行为

| 项目 | 当前行为 |
| --- | --- |
| 测试集只有输入 | `DatasetBody` 和可移植 JSON 均移除输出 Schema、案例标准答案及参考绑定。流程与模块继续定义实际输出。 |
| 多字段输入组 | 详情每组使用独立边框，组内复用素材池行列表：素材、预览、文字内容、分类/标签；每字段一行，按序编号。字段编辑、成员修改和输入专用导入导出可用。 |
| 素材编辑入口 | 只有素材池使用编辑弹窗。其他区域只读预览，点击素材名称或文字内容，通过新标签页 `/assets/{id}?q={name}` 搜索定位并打开当前素材，不显示独立跳转按钮。 |
| 图片查看 | 所有媒体预览共用 `ImagePreview`，点击完整缩略图打开大图弹窗，关闭恢复焦点；图片查看不触发编辑。 |
| 编辑按钮 | 共用有边框、图标加文字、32px 高度的 `EditAction`；删除沿用相同基础样式。 |
| 输出判定 | 新建评测默认 AI 正确性维度，绑定实际输出与原始输入。不从输入文字、素材标注或模块名推断标准答案。运行错误、结构和耗时仍有平台检查。 |
| 模型凭证 | 模型表单直接填写 API Key，后端在同一保存事务创建加密凭据并保存引用。留空保留，替换产生新引用，冲突回滚。正文不回显、不进浏览器草稿/快照/导出。Git/镜像访问凭据在对应表单配置。 |
| 删除与恢复 | 删除保留数据库 `hidden` 及历史，移除回收站和恢复 API。只能由数据库管理员恢复。 |
| 界面简化 | 移除顶部搜索、刷新、凭据管理、侧栏回收站和底部连接/版本文案；移除默认工作区卡片及面包屑工作区前缀。后台实时连接继续同步资源，保留语言、主题、导览及退出。列表筛选和实际仓库同步继续使用各自入口。 |

任务报告、执行历史和执行详情的输入及最终输出采用共用编号组件：从 1 开始，按有序契约标注字段，保留名称和类型。尚未形成的输出不补造内容，已形成字段保留其原始位置编号。2026-10-12 的最新四项布局反馈也已同步到 demo。

## 数据库恢复

没有前端或 HTTP 恢复接口。管理员核对身份后在数据库操作，例如：

```sql
UPDATE resources SET hidden = false WHERE id = '<resource_id>';
UPDATE tasks SET hidden = false WHERE id = '<task_id>';
```

仅修改所需身份的可见性，不删除修订或改写执行。界面重新加载后读取数据库状态。数据库操作必须使用目标环境的管理连接，不在浏览器或文档中暴露连接凭据。
