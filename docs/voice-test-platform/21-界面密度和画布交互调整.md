# 界面密度与画布交互调整

2026-10-12，根据最新界面反馈调整正式前端与 `docs/demo.html`。本记录补充原先的原型验收；这些区域以本次要求为准，旧截图不再作为该布局的视觉基准。

## 五项调整

| 要求 | 已实现的行为 |
| --- | --- |
| 下拉控件紧凑且风格统一 | 共用 32px 触发按钮、11px 文本、12px 箭头；选项使用相同 Tokens，统一边框、圆角、主题和焦点反馈。模块配置使用宿主 Select 时也采用同一风格。 |
| 评测配置采用卡片 | 列表仅显示名称、版本、规则与模型摘要；点击卡片打开只读详情，详情 URL 可直接访问与刷新。右下角编辑按钮打开编辑弹窗，保留草稿、失败重试与版本冲突处理。 |
| 统一删除表达 | 资源、字段、案例、任务配对和节点使用“删除”文案；资源操作显示垃圾桶图标，回收站支持七类资源恢复。版本、媒体和报告历史继续保留，后端 `hide` / `restore` 契约不变。 |
| 画布按需配置 | 默认只有全宽画布；右上角 `+` 展开可搜索的节点库，关闭或 Escape 收起，添加后自动收起。拖动不弹窗，点击节点打开右侧抽屉。开始编辑输入字段组，结束编辑统一输出字段组并同步全部出口。模块和内置节点各自配置参数、映射和节点超时。流程名称、说明、准备和收尾超时在独立设置弹窗编辑，取消不应用，保存进入流程草稿。 |
| 去掉页面介绍 | 九个主页面去掉英文编号和介绍段落，仅保留紧凑标题与操作；版本、执行 ID 和创建时间等实际资源信息继续按详情需要展示。 |

节点抽屉内的快捷键保存失败会在抽屉中显示错误，保留字段并支持再次保存；版本冲突在当前抽屉中查看与处理。缩放时节点标签使用画布缩放值调整，改善完整 DAG 视图的可读性。
