# 测试集与输入组

## 当前边界（2026-10-12 最新决策）

测试集只定义有序输入结构和一组组的输入，不配置输出 Schema、标准答案、参考来源或确认标准。每个输入组完整绑定全部输入字段，调用一次流程。多个输入组依次或按任务有效并发执行。

流程和模块仍定义实际输出结构，平台据此执行、收集结果、校验媒体与结束状态。答案是否正确由独立评测模型根据原始输入、实际输出和评分要求判断，不要求测试集预填答案。完成状态、输出结构和耗时规则用于运行检查。

此决策取代此前本页的“测试集预期输出和可选参考”设计。

## 输入结构

| 顺序 | 名称 | 类型 | 内容 |
| --- | --- | --- | --- |
| 1 | question | Text | 问题 |
| 2 | audio | Audio | 音频素材 |
| 3 | image | Image | 图片素材 |
| 4 | context | JSON | 结构化上下文 |

字段按数组保存，名称唯一。测试集和流程开始组严格匹配名称、类型、顺序与格式；完整素材可以由开始节点生成流式输入，流式属性由流程声明。不同 Text 字段必须有不同名称，不按相似名字自动映射。

每组输入必须提供全部字段。素材绑定保存全局素材 ID；日常预览使用最新修订，创建任务时冻结实际版本、内容、代码、流程和模型配置。修改素材池会更新日常引用，已创建的排队项、执行、重跑和报告继续使用原快照。

```json
{
  "name": "多模态输入",
  "input_schema": {
    "fields": [
      {"name": "question", "type": "Text", "format": "UTF-8"},
      {"name": "image", "type": "Image", "format": "Image/*"}
    ]
  },
  "cases": [
    {
      "id": "group-1",
      "name": "第一组输入",
      "inputs": {
        "question": {"asset_id": "text-asset-id"},
        "image": {"asset_id": "image-asset-id"}
      }
    }
  ]
}
```

文字和 JSON 也可作为输入字面量配置，媒体必须使用验证过的素材。输入组不是对话步骤或内部会话历史。

## 界面

测试集卡片仅显示输入组数量、输入字段和版本。详情只展示输入结构，下方每组输入用独立边框分隔，组内复用素材池列表：每个字段一行，列出素材、预览、文字内容、分类与标签。字段从 1 开始按声明顺序编号，音频可播放，图片可查看大图。编辑按钮为统一有边框按钮，编辑的是输入组绑定。

素材内容只在素材池编辑。其他页面的预览只读；点击素材名称或文字内容，在新标签页跳转到 `/assets/{id}?q={name}`，定位搜索并打开当前素材编辑器，不再显示单独的“打开素材池”按钮。点击图片打开独立大图弹窗。播放、看图和跳转不改写案例或执行证据。

创建向导为输入结构、输入组、确认保存三个步骤，支持字段新增/删除/排序、多字段输入、组成员编辑与移除、单字段素材批量加入和草稿保留。相同实际输入自动去重。

## 版本和删除

新增或移除输入组、重新绑定素材、修改输入结构产生新测试集版本。删除资源只将数据库 `hidden` 标记设为 true，历史数据仍可读取；没有回收站或恢复 API，恢复只能由管理员在数据库操作。

迁移 `a2d91c50b7e4` 为旧测试集追加输入专用的新修订，保留旧修订和已完成任务、执行、报告。旧的包含输出或标准答案的修订仅供历史查阅，新任务和导出选择当前修订。

## 导入导出

`testflow.dataset.v1` JSON 保存名称、说明、有序输入和输入组。输入用 `{value: ...}` 或文件内 `{asset_key: ...}`，不包含输出或标准答案。依赖清单只包含实际输入素材；导入先匹配素材摘要，必要时导入配套素材 ZIP，再显式提交。资源 ID 在目标环境重新产生。

详情支持导出测试集及配套素材。默认导出当前素材修订；API 可指定输入专用测试集的结构/成员版本。错误、缺依赖及关闭保留导入草稿，重复提交遵循幂等键。见 [数据交换契约](../../contracts/data/README.md)。

## 验收

多字段输入组、音频播放、大图、素材池新标签页定位、修改同步、输入专用导入导出、不同流程输出结构和 AI 通过/失败结果均有专项测试。AI 通信夹具与真实模型联调证据分别标记；没有模型评分时不虚构正确性结论。最新证据见 [第 23 篇记录](23-输入组与简化工作区.md)。
